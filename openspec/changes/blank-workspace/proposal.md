## Why

仓库目前为空，无法提供一个可运行的 StudyPower Web 入口。现在先建立最小页面骨架，用于验证项目能够启动并作为后续思维导图和文档工作台的承载页面。

## What Changes

- 创建一个可本地运行的 Next.js Web 应用。
- 增加仅包含顶部导航栏的页面。
- 保持导航栏以下的页面内容为空白。
- 增加本地构建和启动检查。
- 将初始代码提交并推送到指定 GitHub 仓库。

## Capabilities

### New Capabilities

- `blank-workspace-page`: 提供只有导航栏、正文保持空白的 StudyPower 初始页面。

### Modified Capabilities

无。

## Impact

- 影响目录：`F:\APP Location\StudyPower`。
- 新增 Next.js、React、TypeScript 项目文件及 OpenSpec 变更记录。
- 新增本地开发、构建和启动命令。
- 需要向 `https://github.com/SnowLove0303/StudyPower.git` 提交并推送初始代码。
