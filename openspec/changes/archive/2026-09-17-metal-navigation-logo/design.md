# Design: 金属质感导航与无边框 Logo

## Approach

- 复用现有导航 DOM，仅把品牌标记从 `S` 改为 `SP`，避免新增 Logo 图片或组件。
- 使用原生 CSS 多层线性渐变、内外阴影和文字裁切实现轻量金属质感。
- 图标保留当前字符来源，仅移除其边框和圆角背景，降低视觉噪声。

## Accessibility

Logo 与图标继续使用 `aria-hidden`，入口文字仍作为可访问名称；颜色调整保持文字与背景的足够对比度。

## Trade-offs

金属效果依赖 CSS 渐变，在不支持文字背景裁切的旧浏览器中会回退为继承色文字，不影响导航功能。
