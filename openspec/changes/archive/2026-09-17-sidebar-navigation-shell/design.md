# Design: 侧边导航工作台外壳

## Context

首页已有快速启动器状态和交互逻辑，但当前阶段只需要一个明确的应用骨架。导航入口需要表达未来工作区边界，右侧区域保持空白以避免提前固化业务设计。

## Approach

- 使用一个静态的导航项数组渲染左侧 `<nav>`，不引入状态管理、路由或数据存储。
- 使用 CSS Flex 布局分离侧边栏和主工作区；桌面端显示文字导航，窄屏端收窄为图标导航。
- 删除快速启动器组件代码和全部关联样式，确保页面不存在旧交互残留。

## Accessibility

- 使用原生 `<nav>`、`<a>` 和 `aria-label` 提供语义结构。
- 当前入口使用 `aria-current="page"`，窄屏隐藏的文字仍保留在 DOM 中作为可访问名称。

## Trade-offs

本次导航入口只保留视觉入口和锚点，不实现实际页面切换。这样可以先验证整体工作台布局；当用户确定某个功能的交互后，再为该入口建立真实路由和页面。
